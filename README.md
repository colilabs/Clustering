# Clustering
This project applies unsupervised machine learning to segment mall customers based on demographic attributes and spending behavior. Using clustering algorithms (K-Means and Hierarchical Clustering), customers were grouped into distinct segments such as high-value spenders, budget-conscious shoppers, and occasional visitors. Exploratory data analysis was used to uncover key behavioral patterns, and cluster profiles were interpreted to generate actionable marketing insights. The results help mall management design targeted promotions, optimize customer engagement strategies, and improve overall revenue allocation.
